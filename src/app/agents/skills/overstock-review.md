# overstock-review

> 积压/滞销复核：判断「能不能打折、打多少、有没有调拨空间」，避免一刀切清仓。

## 适用场景
- 用户问「这个款压了多少货 / 要不要打折 / 别的仓能不能调走」。

## 步骤
1. `get_inventory` 取可用库存，`get_sell_through` 取预计售罄天数。
2. 分级：可供天数 60–90 天 → 观察；≥90 天 → 积压；近 7 天日均 < 3 件 → 滞销。
3. 调 `create_transfer_suggestion` 看跨仓调拨可行性（同款其他仓有货 → 优先调拨而非清仓）。
4. 计算资金占用：可用库存 × 吊牌价 × 折扣系数，评估清仓折扣的毛利影响。
5. 给出处置建议：调拨 > 换季前促销 > 清仓，并写清触发条件。
6. 若确实要清仓：按清仓 SOP 写明**折扣（平台下限 6 折）**与**分批放量（首轮 40%）**，
   缺这两项预案会被校验 Agent 判为不合规；大促窗口（30 天内有活动）内的高库存属正常备货，
   不得按积压处理。

## 取数工具
- `get_inventory`、`get_sell_through`、`get_sales`、`create_transfer_suggestion`

## 输出模板
1) 积压等级与关键指标；2) 资金占用估算；3) 处置建议（按优先级）+ 依据 result_id。
